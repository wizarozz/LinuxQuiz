# Linux Квиз (Android)

Викторина на 1000 вопросов по Linux: 4 варианта ответа, подсчёт баллов, история результатов.

## Как открыть и запустить
1. Установите Android Studio (Koala 2024.1 или новее) — JDK 17 идёт в комплекте.
2. File → Open → выберите папку `LinuxQuiz`. Дождитесь Gradle Sync (нужен интернет).
3. Выберите эмулятор или подключите телефон (включите отладку по USB) и нажмите ▶ Run.
4. Для установочного файла: Build → Build APK(s) (или Generate Signed Bundle / APK для публикации).

## Возможности
- Выбор темы (10 тем) или «Все темы», число вопросов: 10 / 20 / 50 / 100 / Все.
- Вопросы и варианты ответа перемешиваются при каждом прохождении.
- Подсветка правильного (зелёный) и неправильного (красный) ответа сразу после выбора.
- Счётчик баллов во время игры; в конце — итог «X / N», процент, оценка.
- Результат каждой игры сохраняется (последние 100) и показывается на главном экране вместе с лучшим результатом.
- «Работа над ошибками» — список вопросов, где вы ошиблись, с правильными ответами.
- Тёмная тема подстраивается под системную.

## Где лежат вопросы
`app/src/main/assets/questions.json`. Формат элемента:
```json
{"id": 1, "topic": "Основы...", "q": "Кто создал ядро Linux?", "options": ["...", "...", "...", "..."], "correct": 2}
```
`correct` — индекс правильного варианта (0–3). Можно добавлять свои вопросы, перезапуск приложения подхватит изменения.

## Структура кода
- `Data.kt` — модели, загрузка JSON, хранение результатов (SharedPreferences)
- `QuizViewModel.kt` — логика игры и подсчёт баллов
- `Screens.kt` — экраны на Jetpack Compose (главный, вопрос, итоги)
- `MainActivity.kt` — точка входа
